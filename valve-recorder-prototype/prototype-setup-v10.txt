設置・操作手順メモ v1.0（仮実装 / Googleスプレッドシート＋Apps Script）
作成：2026-11-19
対象：prototype-template-v10.xlsx ／ prototype-gas-v10.txt
（本人が自宅のGoogleアカウントで行う手順。上から順番に進めること）


■ 1. ブックを Googleスプレッドシートへインポートする
1. Googleドライブ（drive.google.com）を開き、「新規」→「ファイルのアップロード」で
   prototype-template-v10.xlsx をアップロードする。
2. アップロードされたファイルを右クリック →「アプリで開く」→「Googleスプレッドシート」。
   ※この時点で開いているのは「.xlsx のまま」の表示。Apps Script が使えないので、次の手順で変換する。
3. 開いた画面のメニュー「ファイル」→「Googleスプレッドシートとして保存」。
   新しいタブで、Googleスプレッドシート形式のコピーが開く。以降はこちらを使う。
4. （確認）メニュー「ファイル」→「設定」→「全般」のタイムゾーンが
   「(GMT+09:00) 東京」になっていることを確認する（違えば変更して「設定を保存」）。
   ※タイムゾーンがずれていても照合結果は変わらないが、メッセージに出る日時がずれて見えるため。
5. シートが17枚あることを確認する：
   設定／設定1／設定2／設定3／操作／リセットログ／抽出1〜3／記録先1-1〜1-3／記録先2-1〜2-3／
   記録先3-1／テスト手順


■ 2. GAS コードを貼り付ける
1. 変換後のスプレッドシートで、メニュー「拡張機能」→「Apps Script」を開く。
2. 左の「ファイル」に「コード.gs」がある。中身（function myFunction() {…}）を全て消す。
3. prototype-gas-v10.txt の中身を全て（先頭の /** から最後の } まで）コピーして貼り付ける。
4. 上部のフロッピーの絵（プロジェクトを保存）を押す。プロジェクト名は任意（例：記録ツール仮実装）。
5. （任意）左の歯車「プロジェクトの設定」→「タイムゾーン」も「(GMT+09:00) Japan Standard Time - Tokyo」にしておく。


■ 3. 初回の承認
1. Apps Script エディタ上部の関数選択欄（「デバッグ」の右）で「onOpen」を選び、「実行」を押す。
2. 「承認が必要です」→「権限を確認」→ 自分のGoogleアカウントを選ぶ。
3. 「このアプリは Google で確認されていません」と出たら、左下の「詳細」→
   「（プロジェクト名）（安全ではないページ）に移動」→「許可」。
   ※自分で貼ったスクリプトなので問題ない。求められる権限は「このスプレッドシートの表示・編集」。
4. 実行ログに「実行完了」と出たらOK。スプレッドシートのタブに戻る。
   （エディタから実行した onOpen はメニューを作らないことがあるので、次の手順で再読込する）
5. スプレッドシートのタブをブラウザで再読込（F5）する。
   数秒後、メニューバーの「ヘルプ」の右に「記録ツール」が出る。
   同時に右下に「開いた時の通知」が出る（テスト手順 X9 の確認になる）。


■ 4. ボタン（2通り。どちらか、または両方）

【方法A：カスタムメニュー（おすすめ。設定不要）】
メニュー名：記録ツール
項目名（上から）と、呼ばれる関数：
  記録実行（全系列）　　　　　→ recordAll
  ───
  プレビュー（系列1）　　　　→ previewSeries1
  プレビュー（系列2）　　　　→ previewSeries2
  プレビュー（系列3）　　　　→ previewSeries3
  ───
  リセット（系列1）　　　　　→ resetSeries1
  リセット（系列2）　　　　　→ resetSeries2
  リセット（系列3）　　　　　→ resetSeries3
  ───
  テスト初期化（仮実装専用）　→ initPrototype

【方法B：操作シートに図形ボタンを置く（本実装の見た目に近づけたい場合）】
※ .xlsx の図形はインポートされないので、Googleスプレッドシート側で作る。
1. 「操作」シートを開き、メニュー「挿入」→「図形描画」→ 図形アイコン →「図形」→ 角丸四角形。
2. 図形の中に「記録実行（全系列）」と文字を入れ、「保存して終了」。
3. 置かれた図形をクリック → 右上の「︙」→「スクリプトを割り当て」→ recordAll と入力 →「確定」。
   （関数名だけを入れる。括弧 () は付けない）
4. 同様に 6個作り、配置と割り当ては次のとおり：
   行6付近の右（D〜F列）：プレビュー（系列1）→ previewSeries1 ／ リセット（系列1）→ resetSeries1
   行11付近の右（D〜F列）：プレビュー（系列2）→ previewSeries2 ／ リセット（系列2）→ resetSeries2
   行16付近の右（D〜F列）：プレビュー（系列3）→ previewSeries3 ／ リセット（系列3）→ resetSeries3
   記録実行（全系列）は行2〜4付近。
5. 図形を移動・編集したい時は右クリック（左クリックすると割り当てた関数が動く）。
※テスト初期化はメニューから使う（本実装には無い機能なので、ボタンは置かなくてよい）。


■ 5. 使い方（本実装と同じ動き）
- 記録実行（全系列）：全系列を走査 → 確認ダイアログ（系列ごとの件数と合計）→「はい」で記録。
  「いいえ」なら何も書かない。結果ダイアログに系列ごとの記録件数・記録できなかった件数が出る。
- プレビュー（系列n）：その系列の記録予定件数・期間・明細を表示するだけ（書き込みなし）。
- リセット（系列n）：操作シートのその系列の「除外開始」「除外終了」セル
  （系列1＝B7/B8、系列2＝B12/B13、系列3＝B17/B18）に日時を入れてから押す。
  日時は「2026/11/17 13:00:00」のように入力する。確認や警告は出ずに実行され、
  その系列のポインタが除外終了日時になり、リセットログに1行増える。
- 設定は「設定」（共通）と「設定1〜3」（系列ごと）のB列を書き換えるだけで反映される。
  グレーの管理欄（設定1〜3 の行24〜27）は触らない（テストで手入力する時だけ例外）。


■ 6. テスト初期化（仮実装専用）の使い方
- メニュー「記録ツール」→「テスト初期化（仮実装専用）」→ 確認で「はい」。
- 戻すもの：記録先（設定1〜3 に書かれた記録先の、開始セルから下の3列）、
  設定1〜3 の管理欄（B24〜B27）、リセットログの2行目以降、操作シートの除外開始／除外終了セル。
- 戻さないもの：設定値（許容差・遡り日数・ON/OFF など）、抽出シートのダミーデータ。
  テストで設定値を変えた場合は、テスト手順シートの指示どおり手で元に戻す。


■ 7. テストの進め方
- 「テスト手順」シートの S1〜S6 を順番に行い、期待結果と見比べて E列に結果を記入する。
- 余裕があれば追加テスト X1〜X9 も行う（設計メモ §13 の T4・T11・T12・T14 などに対応）。
- 【日付の注意】ダミーデータは 2026/11/17〜18。遡り日数が初期値7日のままだと、
  2026/11/24 07:00 頃より後に試すと古い立ち上がりから順に対象外になり、件数が期待結果より減る。
  その場合は 設定1〜3 の B18（遡り日数）を 3650 に変えてから試す。


■ 8. うまく動かない時
- メニュー「記録ツール」が出ない：ブラウザで再読込する。それでも出なければ手順3の承認をやり直す。
- 「承認が必要」と毎回出る：手順3を最後（許可）まで進めていない。
- 「他の処理が実行中です」：前の操作が終わるのを待ってからもう一度。
- エラーダイアログ：メッセージにシート名とセル番地（例：設定2 B19）が出るので、その設定値を確認する。
