1. 設計メモとの対応
==================================================
【§1 ログ方式】
　・訪問のたびに visits に1行追加。同じ店に何度でも記録できる
　・spots.status は訪問ログからの従属項目：ログ1件以上＝「行った」、0件＝「行きたい」。
　　GAS 側で addVisit／updateVisit／deleteVisit のたびに再計算し、変わった時だけ
　　そのスポットの1行を書き換える。updateSpot で status を送っても無視して再計算、
　　addSpot は常に「行きたい」。編集画面の「状態」セレクトは撤去（表示のみ）

【§2 visits タブ】
　列：visit_id（V0001形式）／spot_id／date／rating（1〜5）／menu／price（合計・円）／
　　companions／people／comment／photos（Drive ファイルIDを「/」区切り、最大5）／
　　repeat（◎○×、任意）／created_at／updated_at
　・タブ全体を書式なしテキスト（日付・金額の自動変換防止）
　・v1.0 の DB に v2.0 の GAS を載せると、最初のアクセスで visits タブが自動作成される
　　（既存の spots・tags・config は触らない）
　・評価の絵文字：1😫もう行かない／2😞いまいち／3😐ふつう／4😋よかった／5🤩最高
　・price と people があれば「1人あたり約◯円」（四捨五入）を自動表示（フォーム入力中も即時）
　・GAS 側の入力チェック：日付 yyyy-MM-dd、評価 1〜5、金額は整数、人数は1以上、
　　また行きたいは ◎○× のみ、写真5枚まで、spot_id の存在

【§3 写真（Google Drive）】
　・アプリ側で長辺1600px・JPEG（品質0.82）に圧縮してから送る（EXIF の向きは補正）
　・GAS uploadPhoto：Drive のフォルダ「スポット帳 写真」（無ければ作成、IDを保存）に保存し、
　　「リンクを知っている全員が閲覧可」に設定してファイルIDを返す
　・表示は https://drive.google.com/thumbnail?id=ID&sz=w◯ （一覧は小、詳細は大、タップで1600）
　・保存の順序：新しい写真を先にアップロード → addVisit／updateVisit → 成功したら外した写真を
　　deletePhoto。保存に失敗したら今回アップロードした写真を消して後始末する
　・deletePhoto は「スポット帳 写真」フォルダ内のファイルだけをゴミ箱へ（他のファイルは拒否）
　・deleteVisit はその訪問の写真もゴミ箱へ移す（Drive のゴミ箱から30日間は戻せる）

【§4 訪問済の表示】
　・一覧（県ページ・ジャンル・検索・近く・最近）：「✅ 訪問済 26/11/17 😋」バッジ
　　（直近の訪問日＋直近の評価）。アイコンも金縁の色付き丸になる
　・地図マーカー：訪問済は白丸 → 薄い金色の丸＋金色の縁＋右上に緑の✓バッジ。
　　絵文字は従来どおり代表タグのもの
　・絞り込み：一覧の上部に「すべて／✅ 訪問済だけ／未訪問だけ」、地図の3つ目のセレクトも同じ
　　（v1.0 の「状態：行きたい／行った」を置き換え。状態は訪問ログ由来なので同じ意味）
　・詳細画面：「✅ 訪問済（3回訪問）」、評価欄は直近の訪問の絵文字、訪問記録の一覧

【§5 思い出ノート】
　・ホームに「📖 思い出ノート」カード（件数の要約と最近の1件）→［開く］でページ表示。タブは増やさない
　・サマリー：訪問したスポット数／訪問のべ回数／行った都道府県数／使った金額の合計
　・タイムライン：訪問日の新しい順（同日は記録の新しい順）、月ごとの見出し付き。
　　写真サムネイル（無ければ評価絵文字）・店名・評価・日付・金額・誰と・コメント抜粋（40字）
　・タップで訪問の詳細 → 編集・削除
　・県ページの達成率バー：選んでいる項目タブごとに「🏆 三重 グルメ 訪問済 12／91 件（13%）」

【§6 記録の流れ】
　・詳細画面［✅ 訪問を記録］→ 記録フォーム（日付＝今日、評価は絵文字5つを大きく、
　　何を／金額／人数／誰と／コメント／また行きたいか／写真）。必須は日付と評価だけ
　・クイック記録：一覧の各行の［行った！］と地図カードの［✅ 行った！］→ 日付＋評価だけの
　　小画面。評価をタップした瞬間に保存。［詳しく書く］でフル入力へ切替も可
　・記録すると status・一覧バッジ・地図マーカー・思い出ノート・達成率に即反映

【§7 ★評価の一本化】
　・編集画面から★入力を撤去。spots.rating 列は残し、値があれば詳細に「（v1.0の★）」として
　　表示だけする（移行データは全て空）
　・並び替え「評価順」＝直近の訪問評価 → 訪問回数 → 名前（未訪問は後ろ）

【§8 GAS】
　getAll …… visits 全件も返す
　addVisit／updateVisit／deleteVisit …… 行単位。status を GAS 側で再計算し、更新後の
　　スポットも返す（updateVisit で spot_id を変えた場合は新旧両方を再計算）
　uploadPhoto／deletePhoto …… 上記 §3
　setup …… 写真フォルダも作る（ここで Drive の権限承認が出る）

2. 要確認（判断に迷ったため仮決めした点）
==================================================
B-1 訪問記録があるスポットの削除：思い出を巻き添えで消さないよう、GAS が HAS_VISITS で
　　拒否する（「先に訪問記録を削除してください」）。訪問記録ごと消せる方がよければ変える。
B-2 importSpots（CSV 取り込み）は status を CSV の値のまま入れ、再計算しない
　　（v1.0 の「内容を変更しない」を守るため。移行CSVは全件「行きたい」なので矛盾は無い）。
　　Takeout 再取り込みの新規分は訪問0件で「行きたい」になる。
B-3 写真の表示 URL（drive.google.com/thumbnail）は Google の公開仕様ではない表示用URL。
　　リンク共有ファイルなら表示できるが、iPhone の Safari（トラッキング防止・Cookie 設定）で
　　表示されるかは実機で要確認。出ない場合は GAS 経由で画像を返す方式に切り替える。
B-4 クイック記録の［行った！］は訪問済のスポットにも出す（2回目以降の記録用）。
　　未処理キュー・地図の「この範囲のスポット」の行にも出る。
B-5 「使った金額の合計」は visits.price（合計金額）の単純合計。1人あたりではない。
B-6 タイムラインに月ごとの見出しを入れた（設計メモに無い追加。見やすさのため）。
B-7 設定タブに「訪問記録CSVエクスポート」を追加（バックアップ用。設計メモに無い追加）。
　　訪問記録の CSV インポートは作っていない。
B-8 訪問日の初期値は端末の今日。created_at／updated_at は GAS 側の当日。
B-9 金額は「3,000」「3000円」と入れても数字だけにして保存する。人数・金額は任意。
B-10 設計メモの位置づけは「v1.0 の運用が安定してから着手」だが、依頼に従い今回実装した。
　　デプロイの時期は本人判断（v1.0 を先に出すか、v2.0 からまとめて出すか）。
　　v2.0 の GAS は v1.0 の DB と互換（visits タブを足すだけ）なので、どちらの順でも移行できる。
B-11 写真のファイル名は「スポットID-訪問日.jpg」。Drive 上で見分けやすくするため。
B-12 iPhone の HEIC 写真は、Safari の写真選択時に JPEG に変換されて渡される想定。
　　変換されずに読めない場合は「画像を読み込めませんでした」と出る。実機で要確認。

4. デプロイ手順書（v1.0 → v2.0、本人の作業）
==================================================
【GAS（同じプロジェクト・同じURLのまま更新）】
　1. スポット帳の GAS エディタを開き、中身を gas-v2.0.gs で丸ごと置き換える
　2. 冒頭の SECRET_PIN を今のパスワードに書き直して保存（置き換えで '0000' に戻るため）
　3. 関数 setup を選んで ▶実行 →「Google ドライブ」の権限を承認
　　（visits タブと、マイドライブに「スポット帳 写真」フォルダができる）
　4. デプロイ → デプロイを管理 → 鉛筆（編集）→ バージョン「新バージョン」→ デプロイ
　　※「新しいデプロイ」を選ぶと URL が変わり、アプリの設定に入れ直しが必要になる
【HTML】
　5. Netlify の index を index-v2.0.html の中身に差し替える
　6. iPhone でアプリを開き直す（右上が「☁️ ◯件」になれば接続OK）
【確認】
　7. どこか1件のスポットで［行った！］→ 絵文字をタップ → 一覧に「✅ 訪問済」が出る
　8. 詳細の［訪問を記録］で写真を1枚付けて保存 → 思い出ノートにサムネイルが出る
　　（出ない場合は要確認 B-3 の件。Drive の「スポット帳 写真」に保存されているかを確認）
【まだ v1.0 をデプロイしていない場合】
　実装メモ-v1.0.txt §4 の手順を、gas-v2.0.gs・index-v2.0.html で行えばよい
　（setup 実行時に Drive の権限承認も一緒に出る）。初期データの取り込みも同じ手順。

5. v2.0.1（2026-11-17）パスワードの記憶／「PINが一致しません」の解消
==================================================
【経緯】本人から「GAS に登録した PIN を打っても『PINが一致しません』が出続ける」
　「アプリが落ちるたびに入力が面倒」との報告・要望。

【実装】
・端末に記憶：localStorage（spotbook_pin_saved）にパスワードを保存し、起動時にハッシュと
　照合できたら自動でロック解除。ロック画面のチェック（既定ON）と設定タブで ON／OFF。
　「今すぐロック」は記憶も消す。パスワード変更時は記憶中なら新しい値に置き換える
・GAS とパスワードを合わせる画面（openGasPinFix）：同期が AUTH で失敗すると自動表示。
　入力値で ping → 成功したら pinHash・セッション・（希望時）記憶をその値にそろえて再同期。
　失敗時はアプリ側の値を変えない
・GAS doGet：{version:'2.0.1', pin_default: SECRET_PIN==='0000'} を返す（値は返さない）。
　アプリは診断として GET し、初期値のまま／旧版のまま／版は新しいが値が違う を出し分ける

【要確認】
B-13 記憶はこの端末のブラウザ保存領域に平文で置く。端末のロックを開けられる人は
　　アプリも開ける（個人利用の割り切り。本人の要望による）。
　　ホーム画面に追加したアプリでは保存が続くが、Safari のタブで開いている場合は、
　　しばらく開かないと iOS が保存内容を消すことがある（その時は再入力→再記憶）。

【自己検証（すべて PASS、全92項目）】
R0 doGet は版と pin_default だけ返す。SECRET_PIN が 0000 なら pin_default=true。
　 AUTH のメッセージに「新バージョンでデプロイ」の案内
R1 不一致で同期 → 原因説明つきの画面が自動で開く（GAS v2.0.1 稼働中と表示）
R2 違う値では接続せず、アプリ側のパスワードも変わらない
R3 SECRET_PIN と同じ値で接続 → アプリのパスワードもその値にそろう（今のパスワード不要）
R4〜R5 記憶ON → アプリを開き直しても入力なしで同期できる
R6 設定タブで記憶を解除 → 次回は入力が必要
R7 ロック画面のチェック（既定ON）で再び記憶
R8 「今すぐロック」で記憶も消えてロック画面に戻る

【デプロイ】
・GAS：gas-v2.0.txt（または .gs）の中身で置き換え → SECRET_PIN を書き直して保存 →
　デプロイ → デプロイを管理 → 鉛筆 → バージョン「新バージョン」→ デプロイ
・HTML：Netlify の index を index-v2.0.html に差し替え
