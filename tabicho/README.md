# 旅帳 v1.0

設計メモ v0.1（Q1〜Q10 確定版）に沿って作った旅行アプリです。Google Apps Script のウェブアプリとして動きます。

- **5タブ**：ホーム／しおり／ドライブ／お金／記録。設定は右上の ⚙️
- **データの置き場所**：旅帳専用のスプレッドシート（初回に自動作成）。端末にもキャッシュするので電波の弱い場所でも見られ、つながった時にサーバへ送ります。他の端末で先に更新されていた場合は、どちらを残すか確認します

## フォルダ構成

```
tabicho/
  gas/            ← GASに貼るのはこの3つ
    Code.gs         サーバ（保存・スポット帳/家計簿連携・経路・天気・為替・カレンダー）
    index.html      画面（build.js で生成。直接編集しない）
    appsscript.json マニフェスト
  integration/
    spotcho_api.gs  スポット帳GASに追加するファイル（家計簿GASは変更不要）
  src/            画面のソース（index.html / styles.css / js/*.js）
  build.js        src → gas/index.html をまとめる
  test/           ロジック・保存処理・画面通しのテスト
```

## セットアップ

### 1. 旅帳GASを作る
1. https://script.google.com で新しいプロジェクト「旅帳」を作る
2. `gas/Code.gs` と `gas/index.html` を同じ名前のファイルとして貼る（HTMLは「ファイル追加 → HTML」で名前を `index`）
3. 「プロジェクトの設定」で「appsscript.json をエディタで表示」をオンにし、`gas/appsscript.json` の内容に置き換える
4. エディタで `setupTabicho` を一度実行して権限を承認する（保存用スプレッドシートが作られ、URLがログに出ます）
5. 「デプロイ → 新しいデプロイ → ウェブアプリ」：実行ユーザー＝**自分**、アクセス＝**自分のみ**
6. 発行されたURLを iPhone の Safari で開き「ホーム画面に追加」

### 2. スクリプトプロパティ（プロジェクトの設定 → スクリプト プロパティ）

| キー | 内容 |
|---|---|
| `SPOTCHO_URL` | スポット帳GASのウェブアプリURL（/exec） |
| `SPOTCHO_PIN` | スポット帳のPIN（画面側には出ません） |
| `KAKEIBO_URL` | 家計簿GASのウェブアプリURL（/exec） |
| `KAKEIBO_PIN` | 家計簿GASの `SECRET_PIN` と同じ値（必須） |
| `SHIFT_MASTER_SS_ID` | 残業時間管理ブックのID（家計簿GASの `SALARY_SS_ID` と同じ）。「勤務マスタ」の勤務名でカレンダーの勤務を見分け、連休を出します |
| `WORK_CALENDAR_ID` | 勤務が入っているカレンダー（未設定ならメインのカレンダー。家計簿と同じ） |
| `WORK_OFF_REGEX` | 休みを表す勤務名・予定名（既定 `休\|公休\|有給\|有休\|OFF\|オフ`） |
| `SHIFT_AKE_IS_OFF` | 夜勤明けの日を休みとみなすか（既定 `false`） |
| `WORK_EMPTY_IS_OFF` | 勤務の予定が無い日を休みとみなすか（既定 `true`） |
| `TRAVEL_CALENDAR_ID` | 予約を登録するカレンダー（未設定なら既定のカレンダー） |
| `TABICHO_SHEET_ID` | 保存先（`setupTabicho` が自動で入れます） |

### 3. スポット帳GASに連携口を足す
`integration/spotcho_api.gs` をスポット帳のプロジェクトに追加し、ファイル冒頭の説明どおり既存の `doPost` の先頭に2行足します。`TABICHO_SPOT_CONFIG` の列名はスポット帳シートの見出しに合わせてください。**既存デプロイを「新バージョン」で更新すればURLは変わりません。**
「行った」の訪問記録（訪問日・★・ひとこと・同行者）は `visits` シートに入り、スポットのステータスも「行った」になります。取り消すと元のステータスに戻ります。

### 4. 家計簿（GAS v7.0 は変更不要）
ほしいもの帳と同じ方式で送ります。
1. 家計簿GASから `loadAll`（PIN付き）で明細と `rev` を読む
2. 旅帳の明細を足す。支出は `catLock="1"` で用途（イベント・旅行・レジャー）と予算区分（特別費・レジャー）を固定。割り勘分の収入はカテゴリー「割り勘」のまま家計簿の判定に任せる
3. `src="tabicho"`・`srcRef`（旅と明細の目印）を付け、同じ明細は二度入らない
4. 明細一式を `baseRev` 付きで保存。別の端末が先に保存していたら読み直してやり直す（家計簿GASが保存前に Logs を10世代バックアップします）

カテゴリー（支払方法）の初期値は家計簿 v7.0 の名前（三井住友ゴールド(NL)・Olive クレジット・PayPayカード・ガソリン代 など）に合わせてあります。
> 家計簿アプリ側では、旅帳の明細は区分固定の印（今は「🛍️ほしいもの帳」と表示）が付きます。`src` が `tabicho` の時に「🧳旅帳」と出すには家計簿アプリの `catLockBadge` に1行足す必要があります。

### 5. 設定（⚙️）
自分の名前・自宅（初期値は亀山）・支払方法と家計簿カテゴリー（カードかどうか）を確認します。「接続テスト」でスポット帳・家計簿・カレンダー・経路の疎通を確認できます。

## 設計メモとの対応（主なもの）

| 設計 | 実装 |
|---|---|
| Q1 ステータス | 検討中（日付なし）→計画中（日付あり）→確定（要予約0件かつ予約済1件以上）→旅行中→精算・記録中→完了。中止・完了だけ手動 |
| しおり／リスト混合 | 日時あり＝工程ゾーン（●と線＋絵文字）、日時なし＝リストゾーン（折り畳み可）。日時を外せば自動でリストへ |
| 絵文字の連続移動 | 各区間＝滞在＋移動の時間枠。経過割合で線上の位置を決め、滞在中も動く（20秒ごと更新） |
| モード切替 | しおり→リスト：時刻は保持して隠す（固定枠・予約は残る）。リスト→しおり：未配置プールへ、保持時刻はワンタップ復元 |
| Q5 工程 | 開始＝前の終了＋移動（自動提案・手動上書き）、🔒固定枠、間に合わない・重なり・営業時間外・定休日の警告、移動時間は経路から自動計算 |
| リスト①〜⑧ | 行ける日バッジ／今日の営業・閉店まで／優先度／近くのスポット／滞在・料金目安／駐車場・最寄り駅／天気／行ったボタン。距離順・閉店が近い順・優先度順。座標なしも残す |
| 乗り物 | 4種を複数選択。リストの乗り物モーダル（車：高速・有料の指定と高速料金の概算／電車：運賃） |
| Q6 スポット帳 | 参照方式（spot_id、開くたびに最新）。削除済み表示・名前の控え。行った/取り消しは即時書き戻し、新しい更新時刻を正。手入力スポットのスポット帳登録 |
| Q7 予約 | 時刻ありは固定枠に自動で入る。要予約の未予約をホームで警告。カレンダー登録はボタン式。金額はお金へ自動 |
| Q7 持ち物 | カテゴリー別、日帰り/1泊/2泊以上・車旅のテンプレート、進捗％、誰の荷物か |
| Q7 ドライブ | 次の目的地、出発カウントダウン（開始−所要−余裕）、ナビ、走行距離、給油→お金、駐車場メモ。車以外は次の駅・空港・港 |
| 金額入力 | 全箇所で割り勘チェック／1人で払う／1人あたり表示、電卓モードとキーボードを欄ごとに切替 |
| Q8 精算 | 端数は払った人、最小送金（n−1回以内）、内訳展開、実支払額・実受取額と端数調整、支出変更でチェックリセット |
| Q8 家計簿 | 自分の負担分を明細ごと。カード払いは引落額の支出＋割り勘分の収入の2本。送信済みの印と二重送信防止 |
| 多通貨 | 精算通貨、支出ごとの通貨とレート（自動・上書き可）、実効レート（両替・戻し・繰越）、為替計算機（現在地→通貨→市場レート、支出へ反映） |
| Q9 記録 | 日ごとメモ、旅の★と感想、写真リンク、自動まとめ、行ったスポット一覧、記録完了 → 「完了にできます」 |
| Q10 行き先提案 | 勤務カレンダーの連休、日数・メンバー・予算・気分（タグ）。エリアで束ね、片道時間で絞り、絶対行きたい優先、定休・季節を反映して3案。タップで検討中の旅を作成 |

## 開発

```bash
node tabicho/build.js              # src → gas/index.html
node tabicho/test/logic.test.js    # 営業時間・割り勘・精算・実効レート・家計簿・工程・ステータス
node tabicho/test/gas.test.js      # Code.gs の保存処理（分割保存・衝突検知）と家計簿連携（偽の家計簿GAS v7.0 相手）
node tabicho/test/smoke.e2e.js     # 画面の通しテスト（Playwright、デモモード）
```

`gas/index.html` をブラウザで直接開くと**デモモード**（サンプルのスポット帳つき、データはそのブラウザだけ）で動きます。

## 前提・注意
- 高速料金は普通車の概算（有料区間の距離×24.6円＋150円）で、ETC割引は含みません
- 経路は GAS の Maps サービス（無料枠あり）を使い、結果は6時間キャッシュします。取れない時は直線距離からの概算を「約」付きで表示します
- 天気は Open-Meteo、為替は open.er-api.com（どちらもキー不要）を使います
- 地図は OpenStreetMap（Leaflet）です
