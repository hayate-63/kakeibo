旅帳 次期モデル Phase 0 PoC v0.1（2026-11-25）
※ 旅帳本体とは別の、検証用の GAS プロジェクトです。旅帳 v1.0.1 には何も影響しません

■ 中身
・実装報告-PoC-v0.1.txt …… むぎ宛の報告（§2 が実機の結果を貼る場所）
・検証ログ-PoC-v0.1.txt …… 模擬サーバ相手の動作確認の結果
・PoC/gas-poc-v0.1.txt …… GAS（Code.gs に貼る）
・PoC/index.html …………… 画面（GAS に「index」という名前で貼る。Netlify 等に置いても動く）
・PoC/appsscript.json ……… マニフェスト
・test/ ………………………… 模擬サーバと動作確認スクリプト（実機の検証には不要）

■ 準備（10分）
1. 新しい GAS プロジェクトを作り、gas-poc-v0.1.txt → Code.gs、index.html → HTML ファイル「index」、
　 appsscript.json → マニフェスト（プロジェクトの設定で表示をオン）に貼る
2. スクリプトプロパティに SECRET_PIN（好きなパスワード）を入れる
3. エディタで setup を1回実行し、権限を承認する（Drive 直下に「旅帳PoC」フォルダができる）
4. デプロイ → 新しいデプロイ → ウェブアプリ（実行ユーザー：自分／アクセス：全員）
5. iPhone の Safari で URL を開き、PIN を入れて［保存して接続確認］。続けて「ホーム画面に追加」もしておく
6. （任意）index.html を Netlify にも置き、そちらで開いた時は GAS の URL も入れる（画面の Origin が違う時の比較）

■ 撮っておくもの（iPhone の 設定 → カメラ → フォーマット）
・「高効率」で：写真1枚（HEIC）、動画30秒（HEVC）
・「互換性優先」で：写真1枚（JPEG）、動画30秒（H.264）
・HEIC・HEVC のまま試すには、写真アプリの共有 →「"ファイル"に保存」してから、画面の2つ目のファイル欄で選ぶ
　（1つ目の欄＝写真アプリから選ぶと、iOS が JPEG／H.264 に変換することがある。どちらになったかは結果に自動で残る）

■ 押す順番（Safari と ホーム画面アプリ の両方で一通り）
1. 「1. セッション発行・Origin の転送」→［テストを実行］
2. 「2. 直接アップロード」：方式＝直接 PUT、チャンク＝4MB、Origin＝送る で
　 ・写真 HEIC／JPEG、動画 HEVC／H.264 をそれぞれ送る
　 ・動画を送っている途中で ①電源ボタンでスリープ → 30秒後に戻る ②別のアプリへ切り替えて戻る
　　 ③アプリを上にスワイプして終了 → 開き直して「未完了のセッション」の［ファイルを選び直して再開］
　 ・項目1 で直接 PUT が「否」だった時は、方式＝GAS 中継 でも送ってみる
3. 「3. 表示・再生」→［一覧］→ 各ファイルで サムネイル／原本表示／Drive プレビュー／Drive で開く を押し、見えたら［成］、
　 見えなければ［否］。動画は Drive の処理に数分かかることがある。共有 ON にして同じことも試す
4. 「4. 参考」：5MB 以下の写真を［GAS 経由で送る］と［直接 PUT でも送る］
5. 「結果」→［Drive に保存］（「旅帳PoC」フォルダに PoC結果_日時.txt ができる）→ その中身を むぎ に渡す

■ 後片付け
