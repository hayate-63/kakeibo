■ 2. 仕様から外れた判断・仕様に書かれていない判断（黙って変えていない箇所の一覧）

1. 【要確認・仕様からの変更】日時の秒換算に CLng を使っていない
   引き継ぎメモ v1.3 §2 は「CLng(Round(シリアル値 * 86400))」と指定しているが、そのままでは動かない。
   2026年の日時のシリアル値は約 46,300 で、×86400 すると約 40億になり、Long の上限（2,147,483,647）を超えて
   「オーバーフローしました」（実行時エラー6）になる。
   この式は、私（Claude Code）が仮実装の実装メモ v1.0 で例として書いたもので、こちらの誤りだった。申し訳ない。
   実装：秒を Double（小数なしの値）で持ち、Int(シリアル値 * 86400 + 0.5) で四捨五入する（関数 ToSec）。
   Double は 2^53 まで整数を正確に表せるので、秒の比較・同一判定は正確。
   Round を使わない理由：VBA の Round は銀行型丸め（.5 を偶数側へ）で、仮実装（JavaScript の Math.round）と
   丸め方が変わるため。「秒に丸めてから全ての比較を秒で行う」という趣旨は守っている。

2. 設定シートの行3の見出し
   設計メモ §8-2 は「行3が見出し『共通設定』」（系列別は『系列設定』）、引き継ぎメモは「行3＝見出し
   『設定項目／設定値／説明』」で食い違う。設計メモを正とし、A3＝「共通設定」（系列別は「系列設定」）、
   B3＝「設定値」、C3＝「説明」とした。コードは行3を読まないので、どちらでも動作は同じ。

3. ポインタを変えなかったリセットのログ（E列）
   「ポインタ不変の旨で1行残す」を、E列（リセット後の処理済みタイムスタンプ）に文字で
   「ポインタ不変（除外終了が現在のポインタ yyyy/mm/dd hh:mm:ss より前のため）」と書く形にした。
   列は5列のまま増やしていない。E列に日時と文字が混在するのが嫌なら、F列（備考）を足す案もある。
   除外終了＝現在のポインタ（同時刻）の場合は「前」ではないので、通常どおり設定する（値は変わらない）。

4. リセットの後にも保存する
   設計メモは「記録成功後は保存方法に従う」とだけ書いている。リセットもポインタを書き換えるので、
   保存しないまま閉じると除外期間が元に戻り、次の記録実行で除外したはずの分が記録される恐れがある。
   そのため、リセットの後も共通設定「記録後の保存方法」に従って保存（または保存を促す）するようにした。
   不要なら ResetSeries の SaveAfter の1行を消せば元の解釈に戻る。

5. 書き込み途中でエラーになった系列があった時も保存する
   ポインタは進めない（仕様どおり）が、書いた行は消さないので、それを含めて保存する。
   次回は同じ立ち上がりが再び対象になり、重複チェックONなら書き済みの記録先には書かれない。

6. 全角の入力を受け付ける
   ON／OFF、列記号、セル番地、数値の設定値は、全角（例：「ＯＮ」「Ａ２」）で入っていても半角に直して読む
   （StrConv vbNarrow）。職場での手入力ミスで止まらないようにするため。仮実装には無い。

7. タイムスタンプは「日付として入っているセル」だけを読む
   仮実装と同じ扱い（文字のタイムスタンプは空白行扱いで走査対象外）。Excel では、セルの値が日付型の時だけ
   日時と見なす。職場の抽出シートで日時が文字として入っていると何も検出されないので、setup-v13 6-1 に
   「=ISNUMBER(A2) で確認」を入れた。

8. 積算値がエラー値（#N/A など）の場合
   §12 の「積算値が空白：記録しない」に準じて、記録しない（理由「照合した積算値がエラー値」）。

9. 開いた時の通知
   Workbook_Open は標準モジュールの Public Sub「Kiroku_NotifyOnOpen」を呼ぶだけ（§11）。
   通知は MsgBox（OKボタンのみ）。Public なのでマクロの登録一覧に出てくるが、ボタンには割り当てない（手順書に明記）。
   走査中にどこかでエラーが出たら、通知全体を諦めて何も出さない。

10. 処理中の配慮
   書き込みの間だけ、画面更新・イベント・自動再計算を止め、終わったら元の状態に戻す（BeginFast／EndFast）。
   エラーで抜けた時も、各 Sub のエラー処理で EndFast を呼んで戻す。確認ダイアログは止める前に出す。

11. メッセージの長さ
   MsgBox は約1024文字までなので、長いメッセージは切り詰める。プレビューの明細は先頭12件まで表示する。

仮実装の実装メモ v1.0 §3 で挙げた判断のうち、引き継ぎメモ v1.3 で確定したもの（ポインタは走査範囲の最後の
自動弁履歴行／0件でも進める／上書きを避けて系列を中断／重複チェックは記録先ごと／弁の値は数値の0・1のみ）は
そのとおりに実装した。確定の記載が無かった残りの判断（件数の数え方、系列名空欄の系列のボタンを直接押した時の
表示、0件でも確認ダイアログを出す、記録停止フラグONでもプレビュー・リセットは動く、記録先1は必須、
ON/OFF に TRUE/FALSE も受け付ける）も、仮実装と同じにしてある。


■ 3. Muse 照合の重点への対応（引き継ぎメモ v1.3 §4）
- 置き場所：標準モジュール modKiroku に本体一式、ThisWorkbook は Workbook_Open だけ（中身は通知の Sub を呼ぶ1行）。
  シートモジュールは使っていない。直書きのシート名は「設定」（定数 SHEET_COMMON）と「設定1〜3」（関数 SeriesSheetName）だけ。
- アドレス表：定数 C_*（設定の行4〜10）と S_*（設定1〜3 の行4〜27）。値の列は B（VAL_COL＝2）。
- ポインタを進めるのは UpdatePointer だけで、呼ぶのは WriteSeries が True を返した系列だけ。
  確認ダイアログでキャンセルした時は、書き込みより前に Exit Sub する。
- 遡り日数は ScanSeries の「ポインタが無い時」の分岐でだけ使う。リセットは endSec < 現在のポインタ なら書き換えない。
- リセットに警告・確認の分岐は無い（入力チェックだけ）。ログは A 実行日時／B 系列名／C 除外開始／D 除外終了／E リセット後のポインタ。
- 受け口7つは引数なしの Public Sub（Btn_RecordAll、Btn_Preview1〜3、Btn_Reset1〜3）で、
  それぞれ Private の RecordAll／PreviewSeries(n)／ResetSeries(n) を呼ぶ。
- 上書き：書く前に3セルが全て空か確かめ、空でなければその系列を中断する。開始列が埋まっている行は飛ばして下の空白を探す。
- 手順書：6シートの全セル、ボタン7つ、テスト用10シートとダミーデータの全値、テスト後の本番切り替えまで書いた。
